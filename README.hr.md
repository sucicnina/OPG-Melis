# 🐝 OPG Melis

[🇬🇧 English](README.md) | 🇭🇷 Hrvatski

Web stranica obiteljskog pčelarskog gospodarstva. Predstavlja gospodarstvo,
proizvode (med, voštane svijeće i ostale pčelinje proizvode) i način narudžbe.

Stranica je na hrvatskom jeziku.

## Stranice

- **Početna**: uvod s kratkim "O nama" i pregledom proizvoda
- **O nama** (`about.html`): priča o gospodarstvu s interaktivnim karticama
  (košnice, lokacije, godišnja proizvodnja meda, članovi obitelji, godina osnivanja)
- **Proizvodi** (`products.html`): vrste meda, voštane svijeće i ostali
  proizvodi, s informacijama o narudžbi
- **Kontakt** (`contact.html`)

## Tehnologije

- HTML5
- CSS3 (zasebna stilska datoteka za svaku stranicu)
- JavaScript bez okvira (`Animation/about.js`, `Animation/product.js`)

Ne trebaju okviri ni alati za izgradnju.

## Struktura projekta

```
index.html          # preusmjerava na Pages/index.html (za GitHub Pages)
Pages/              # početna, o nama, proizvodi, kontakt
Styles/             # CSS datoteke
Animation/          # JavaScript za interaktivne elemente
Images/             # fotografije, logo, video
```

## Lokalno pokretanje

Otvori `index.html` (ili `Pages/index.html`) u pregledniku. Server nije potreban.

## Napomena o privatnosti

Stvarna adresa, telefonski brojevi, e-mail i poveznica na kartu uklonjeni su
sa stranice Kontakt u ovoj javnoj verziji.

Samostalni projekt: sama sam osmislila i izradila cijelu web stranicu za
