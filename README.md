# 🐝 OPG Melis

🇬🇧 English | [🇭🇷 Hrvatski](README.hr.md)

A website for a family beekeeping farm. It presents the farm, its products
(honey, beeswax candles and other bee products) and how to order.

The site is in Croatian.

## Pages

- **Home**: introduction with a short "About us" and product overview
- **About us** (`about.html`): the farm's story, with interactive info cards
  (hives, locations, yearly honey production, family members, founding year)
- **Products** (`products.html`): honey varieties, beeswax candles and other
  products, with ordering information
- **Contact** (`contact.html`)

## Tech Stack

- HTML5
- CSS3 (a separate stylesheet per page)
- Vanilla JavaScript (`Animation/about.js`, `Animation/product.js`)

No frameworks or build step are needed.

## Project Structure

```
index.html          # redirects to Pages/index.html (for GitHub Pages)
Pages/              # index, about, products, contact
Styles/             # CSS files
Animation/          # JavaScript for interactive elements
Images/             # photos, logo, video
```

## Running Locally

Open `index.html` (or `Pages/index.html`) in a browser. No server is required.

## Privacy Note

The farm's real address, phone numbers, e-mail address and map link were
removed from the contact page in this public version.
